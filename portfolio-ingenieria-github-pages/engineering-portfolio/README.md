# Engineering Portfolio — GitHub Pages

A responsive, single-page engineering portfolio using plain HTML and CSS. No build tools, dependencies, or paid hosting required.

## Personalize it before publishing

Open `index.html` in your editor and:

1. Change `YOUR_EMAIL@example.com` (appears 3 times) to your actual email address.
2. Change `https://www.linkedin.com/in/YOUR_LINKEDIN/` to your LinkedIn profile.
3. Review the descriptions of projects and experience; do not publish confidential employer drawings or data.
4. Add links to your own CAD screenshots, project videos, PDFs, or GitHub repositories.
5. Optionally change the title, colors in `styles.css`, and header initials.

## Publish for free with GitHub Pages

1. Log in to GitHub. Create a **public** repository named `<YOUR_GITHUB_USERNAME>.github.io` (replace the placeholder with your actual GitHub username). If using GitHub username `SMGA08`, name it `SMGA08.github.io`.
2. Upload **both** `index.html` and `styles.css` to the root of the repository (not inside a folder); commit them to the `main` branch.
3. In the repository open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Choose **main** and **/(root)**, then save.
4. Visit `https://<YOUR_GITHUB_USERNAME>.github.io/` once GitHub finishes deploying.

To update the page later, edit and commit the files; GitHub Pages will publish the changes.

## Local preview

Double-click `index.html` to open it in a browser. For an editor workflow, use VS Code with the Live Server extension (optional).

## Files

- `index.html`: page content and layout
- `styles.css`: responsive design
- `README.md`: setup and publication instructions
